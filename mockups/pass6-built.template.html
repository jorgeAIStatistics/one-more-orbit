Something I found and fixed on the way. When the game ran from the development server (the one I record from, port 5199), it read the hand-charted notes of the folder named after each world's id. Emberwick's id is "heroes", so that was the old Heroes Tonight folder, which has none. Emberwick then fell back to the chart's automatic split, and Cirra, Glassmere and Verdance were affected the same way. The build you play at 4173 always read the right files. So your playtests were right, but my development-server recordings and frame measurements last pass used slightly different taps from the audit. Each world now reads its own song's folder.

6. How the engine does it

  • The course is unchanged underneath. It is still beats, angles and ring heights. Each place maps those to its own shape: an ellipse, a figure-eight, a straight bridge, or a circle that spirals in. Each shape is as long as the circle it replaces, so a beat always covers the same distance and the speed you see matches the music. Levels without places are drawn exactly as before.
  • A launch is a new bar word, leap (leap4 for the fling, leap2@2 for the strike on a bar's third beat). The taps charted inside its flight become embers, which work like mid-air orbs. Nothing is asked for a beat after the landing, and the first tap after it gets the wider window.
  • The places' layout is in Emberwick's level file. It runs upward on a phone and is turned to run left to right on a wide screen.
